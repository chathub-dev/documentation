# Create First Project

## Sample Projects

The home page features examples for four common use cases to help you quickly explore Notebook’s core capabilities. When you select a sample project, a copy will be added to your personal workspace. You cannot upload your own files to sample projects, but you can explore the full experience, including chat and report export.

## How to Use Notebook

Upload your source materials, including PDFs, EPUB files, MP3s, and other supported formats.

<Frame>
  ![Image](/images/image-2.png "Image")
</Frame>

You can then use natural language to ask anything about your source materials after waiting for a moment. You can also combine them with web search results—for example: “Search the web and provide a comprehensive analysis of \[topic\].”

<Frame>
  ![Image](/images/image-3.png "Image")
</Frame>

When you want a report that you can save and refer to over time, ask the AI: “Create a comprehensive report on \[topic\] for future reference.” The report will appear in the panel on the right.

<Frame>
  ![Image](/images/image-4.png "Image")
</Frame>
